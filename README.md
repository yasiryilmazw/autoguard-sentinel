# 🛡️ AutoGuard Sentinel

**AutoGuard Sentinel**, Python, Flask ve OpenCV kullanılarak geliştirilmiş akıllı, web tabanlı bir güvenlik ve canlı kamera takip sistemidir. Gerçek zamanlı hareket algılama yapar ve güvenli bir yönetici paneli sunar.

---

## 🌟 Öne Çıkan Özellikler

- 📹 **Canlı Video Yayını**: Web tarayıcısı üzerinden kesintisiz güvenlik kamerası takibi.
- 🎯 **Gerçek Zamanlı Hareket Algılama**: OpenCV ile görüntü işleme ve otomatik hareket tespiti.
- 🔐 **Yönetici Giriş Paneli**: Yetkisiz erişimi engelleyen güvenli giriş/çıkış altyapısı.
- 📊 **Yönetim Paneli**: Sistem durumunu ve güvenlik uyarılarını izleme.
- 📱 **Responsive Arayüz**: Mobil ve masaüstü cihazlara uygun web arayüzü.

---

## 🛠️ Kullanılan Teknolojiler

- **Backend**: Python, Flask
- **Görüntü İşleme**: OpenCV, NumPy
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
